PROYECTO: MI ESPACIO CREATIVO
MÓDULO 4 - CSS

DESCRIPCIÓN

Este proyecto consiste en la creación de una página web utilizando HTML5 y CSS. 
El propósito de la actividad es aplicar diferentes técnicas de diseño web, 
incluyendo selectores CSS, colores, tamaños, márgenes, modelo de caja y diseño 
responsivo.

ESTRUCTURA DEL PROYECTO

El proyecto contiene los siguientes archivos y carpetas:

- index.html
  Contiene la estructura principal de la página utilizando HTML5.

- styles.css
  Contiene los estilos utilizados para diseñar y organizar la página.

- README.txt
  Contiene la información y explicación del proyecto.

- imagenes/
  Contiene las imágenes utilizadas en la página web.

ESTRUCTURA HTML5

La página utiliza diferentes elementos semánticos de HTML5:

- header: contiene el encabezado principal.
- nav: contiene el menú de navegación.
- main: contiene el contenido principal.
- section: divide el contenido en diferentes secciones.
- article: contiene información independiente de cada proyecto.
- footer: contiene la información final de la página.

CSS UTILIZADO

En el proyecto se utilizaron diferentes tipos de selectores:

- Selectores de elementos.
- Selectores de clase.
- Selectores de ID.

También se utilizaron propiedades CSS para modificar colores, tamaños, 
espaciado, bordes, fuentes y otros elementos visuales.

MODELO DE CAJA

Se aplicó el modelo de caja utilizando propiedades como:

- margin
- padding
- border
- width
- box-sizing

DISEÑO RESPONSIVO

La página incluye un diseño responsivo mediante una regla @media. 
Esto permite que el contenido se adapte a diferentes tamaños de pantalla, 
como computadoras, tabletas y teléfonos móviles.
